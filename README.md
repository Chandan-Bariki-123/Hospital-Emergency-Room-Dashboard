# Hospital Emergency Room Dashboard

## 📊 Project Overview

This project presents an interactive Hospital Emergency Room Dashboard created using Microsoft Excel.

The dashboard is designed to analyze emergency room patient data and provide a clear overview of patient volume, waiting time, satisfaction, admission status, attendance status, gender distribution, age groups, and department referrals.

The goal of this project is to transform healthcare data into meaningful insights using Excel data analysis and visualization techniques.

---

## 🎯 Project Objectives

- Analyze hospital emergency room patient data
- Monitor patient volume and attendance status
- Analyze average patient waiting time
- Understand patient satisfaction
- Analyze patient distribution by gender and age group
- Compare admitted and non-admitted patients
- Analyze department referral patterns
- Provide an interactive monthly analysis

## 📈 Dashboard Features

### Patient Overview

The dashboard provides an overview of the total number of emergency room patients along with average waiting time and patient satisfaction.

### Attendance Analysis

Patient attendance is analyzed using:

- On Time
- Delay

### Gender Analysis

The dashboard shows the distribution of patients by:

- Male
- Female

### Age Group Analysis

Patients are grouped into different age categories:

- 0–9
- 10–19
- 20–29
- 30–39
- 40–49
- 50–59
- 60–69
- 70–79

### Admission Analysis

The dashboard compares:

- Admitted Patients
- Not Admitted Patients

### Department Referral Analysis

The dashboard provides an overview of patient referrals across different departments.

### Monthly Analysis

Users can analyze patient data across different months using the interactive month selection.
